# Backend Domain Model

> Entities, fields, relationships, invariants. Reflects current migrations + planned additions.

## Entities

### User
`id, name, email(unique), password(hashed), role, timestamps`
- `role`: `user | admin | super_admin` (target: `UserRole` enum).
- Helpers: `isAdmin()`, `isSuperAdmin()`.
- Relations: `hasMany(AccessCode)`, `hasMany(ShortUrl)`.
- Auth: `HasApiTokens` (Sanctum).

### AccessCode
`id, user_id(fk→users, cascade), code(unique,≤100), is_active(bool,default true), expires_at(nullable), last_used_at(nullable), timestamps`
- Indexes: `(user_id, is_active)`, `expires_at`.
- Invariant: `isValid()` = active **and** not expired.
- Role: the **gate** for creating short URLs. A create request must present a valid code; `validateAndConsume` marks `last_used_at`.

### ShortUrl
`id, user_id(fk→users, cascade), short_code(unique,≤32), long_url(text), is_active(bool,default true), click_count(unsigned big,default 0), expires_at(nullable), last_accessed_at(nullable), timestamps`
- Indexes: `(user_id, is_active)`, `expires_at`, unique `short_code`.
- Invariant: `isValid()` = active **and** not expired.
- `short_code` generated by `ShortCodeGenerator` (base62, non-enumerable — ADR-0001).
- `click_count` is the cheap coarse counter incremented on redirect; rich per-click data lives in `clicks`.

### Click (Planned — D5)
`id, short_url_id(fk→short_urls, cascade), ip(nullable), user_agent(text,nullable), browser(nullable), os(nullable), device_type(nullable), referer(nullable), country(nullable), created_at`
- Written by the Kafka `clicks:consume` worker after user-agent enrichment.
- Indexes: `short_url_id`, `created_at` (for time-series aggregates).
- Source for dashboard aggregates (clicks over time, device breakdown, top URLs).

## Relationships
```
User 1───* AccessCode
User 1───* ShortUrl
ShortUrl 1───* Click   (planned)
```

## Lifecycle notes
- **Create URL:** requires valid AccessCode → ShortUrl row + generated code.
- **Redirect:** validates ShortUrl (`isValid`), caches, increments `click_count`, emits event.
- **Expiry:** `expires_at` past ⇒ `isValid()` false ⇒ 404 on redirect; cache TTL derived from `expires_at`.
- **Admin mutations:** update/delete a ShortUrl busts its Redis cache entry.
